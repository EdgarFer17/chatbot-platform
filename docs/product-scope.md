# Escopo atual — FAFIC

A instalação atende somente a FAFIC. O painel possui acesso por senha, ligar/desligar, mensagem de indisponibilidade e gestão de documentos. A conversa pública ocorre pelo widget no site.

A documentação pode ser enviada, revisada, publicada e sincronizada na seção Documentos do painel, usando a API existente. Apenas publicações aprovadas são utilizadas nas respostas. O bot responde em linguagem natural e pode exibir fontes discretas; não apresenta títulos de documentos como cabeçalho da resposta.

Não fazem parte da interface: carteira de instituições, ambientes, cotas, credenciais, auditoria. O armazenamento multi-instituição continua preservado para compatibilidade e possível evolução futura.

Não existe transferência automática para atendimento humano. Um contato pode ser escrito pelo administrador no aviso de indisponibilidade.

Para implementação, validação e limitações, consulte [fafic-delivery.md](fafic-delivery.md).
